# 008 — Game AFK Timer Wiring (EPIC-13.0)

## Status

Accepted

## Context

`ReconnectService::ensureGameAfkTimer(object $worker, int $roomId)` is fully
implemented and unit-tested (EPIC-8.3) but has zero production callers.
`GameService::handleStartGame()` sets `active_drawer_conn_id` and broadcasts
`game_started` but never sends `your_turn` or arms the game AFK timer.
`handleDrawBarrel()` calls `sendYourTurn()` on rotation but never arms the
timer. Drawer-replacement paths (`ReconnectService::removePlayerFromGame()`,
`ApartmentService::finishApartment()`) have the same half-wiring.

`GameService` currently has no `ReconnectService` dependency. `sendYourTurn()`
does not receive `$worker`, which `ensureGameAfkTimer()` requires.

Options evaluated:

| Option | Description | Assessment |
|--------|-------------|------------|
| (a) Inject `ReconnectService` into `GameService` constructor | Direct DI | **Rejected** — circular dependency: `ReconnectService` already depends on `GameService` in its constructor. Would require constructor reordering or lazy resolution across multiple files. |
| (b) Pass `$worker` into `sendYourTurn()`; caller arms timer at every call site | Scatter `ensureGameAfkTimer()` after each `sendYourTurn()` | **Rejected** — four call sites, easy to miss on future changes; violates DRY for an atomic turn-start operation. |
| (c) `GameService::startTurn(array &$room, object $worker, int $roomId)` | Sends `your_turn` and arms AFK timer in one call | **Accepted** — single mechanical call at every turn-start site; `sendYourTurn()` remains the internal packet/afk_start primitive. |

## Decision

1. Add `GameService::startTurn(array &$room, object $worker, int $roomId): void`
   that (a) calls existing `sendYourTurn($room)` and (b) calls
   `ReconnectService::ensureGameAfkTimer($worker, $roomId)` when a reconnect
   service reference is available.

2. Wire `ReconnectService` into `GameService` via **post-construction setter**
   (`setReconnectService()`) in `server.php`, after both objects are
   constructed. This breaks the circular constructor dependency without
   changing `ReconnectService`'s existing constructor signature.

3. Replace `sendYourTurn()` with `startTurn()` at these call sites:
   - `GameService::handleStartGame()` — end, after `game_started` broadcast
   - `GameService::handleDrawBarrel()` — after `nextDrawer()`, rotation path
   - `ReconnectService::removePlayerFromGame()` — when `wasDrawer`
   - `ApartmentService::finishApartment()` — when game resumes to `playing`

4. `sendYourTurn()` remains public for direct unit tests (GROUP 1 in
   `test_turn_system.php`); production turn-start paths use `startTurn()`.

## Module boundary

**Does NOT cross a module boundary.** Both `GameService` and
`ReconnectService` live in `src/Game/` (ANCHOR_CORE.md Part 3 — Game module).
No import from Auth, Lobby, Admin, or Infrastructure beyond existing deps.

## Anchor document impact

**No amendments required.** This is pure internal wiring:

- Room/Player structure — unchanged
- Timer Registry fields (`game_afk_timer_id`, `afk_start`) — already defined; now populated
- Protocol packets (`your_turn`, `afk_warning`) — already specified; no shape changes

## Consequences

- EPIC-13.1/13.2/13.3 each add a single `startTurn()` call (or equivalent
  via `gameService->startTurn()` from sibling services) at their respective
  sites — mechanically identical pattern.
- `server.php` gains one line: `$worker->gameService->setReconnectService(...)`.
- Tests without `setReconnectService()` still pass packet assertions; AFK
  timer assertions require the setter or a mock `ReconnectService` (EPIC-13.4).
- `ensureGameAfkTimer()` is idempotent (creates timer once per room); calling
  it on every `startTurn()` is safe — subsequent calls no-op while timer exists;
  per-turn `afk_start` reset remains in `sendYourTurn()`.
