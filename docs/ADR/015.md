# 015 — Extract GameTurnService from GameService

## Status

Proposed

## Context

`src/Game/GameService.php` is **812 lines** (2026-08-02 audit), past the
**700-line warning** threshold in `ANCHOR_CORE.md` § File Size Policy and
approaching the **1000-line mandatory refactor** line. The same file already
triggered ADR-002 (GameFinishService extraction at ~1000 lines); it has
regrown since Phase 8–16 feature work without further decomposition.

Current `GameService` responsibilities:

| Cluster | Approx. lines | Methods |
|---------|---------------|---------|
| Game start (Phase 4) | ~230 | `handleStartGame()`, `buildInitialMasks()` |
| Turn / draw / mark (Phase 5) | ~360 | `sendYourTurn()`, `handleTurnReady()`, `startTurn()`, `nextDrawer()`, `handleDrawBarrel()`, `broadcastBarrelsDrawn()`, `markNumber()`, `numberToColumn()`, `peekNextDrawer()`, `calculateWinChances()` passthrough |
| Apartment delegation | ~30 | `triggerApartment()`, `handleApartmentChoice()` |
| Finish delegation (ADR-002) | ~40 | `finishGame()`, `handleNoSurvivors()` |

`ApartmentService` (631 lines) and `AdminService` (517 lines) exceed the
300–500 target but remain below the 700-line warning; they are **out of
scope** for this ADR.

## Decision

Extract **one** cohesive cluster into a new service when line count nears
1000 or the next large Epic touches turn logic:

### Primary extraction: `GameTurnService`

**New file:** `src/Game/GameTurnService.php` (~350–400 lines)

**Moves from GameService (no behaviour change):**

- `sendYourTurn()`
- `handleTurnReady()`
- `startTurn()` — retains `ReconnectService` wiring via constructor injection
- `nextDrawer()`
- `handleDrawBarrel()` — full draw pipeline including victory/apartment hooks
- `broadcastBarrelsDrawn()` (private → public or package-internal on new service)
- `markNumber()`
- `numberToColumn()` (private helper)
- `peekNextDrawer()` (private helper)

**GameService keeps:**

- `handleStartGame()` + `buildInitialMasks()` — distinct lifecycle entry;
  stays until a second extraction Epic if needed.
- Thin delegation to `GameTurnService`, `ApartmentService`, `GameFinishService`,
  `VictoryService` (same pattern as current `finishGame()` passthrough).
- `calculateWinChances()` passthrough to `VictoryService` (or move with
  `broadcastBarrelsDrawn` if that simplifies wiring).

**Dependencies (constructor):**

```php
GameTurnService(
    object $db,           // only if draw path needs stmts — verify at implementation
    object $stmts,
    object $logger,
    LottoEngine $engine,
    VictoryService $victory,
    ApartmentService $apartment,
    GameFinishService $finishService,
    ?ReconnectService $reconnectService  // set after construction (ADR-008 pattern)
)
```

Circular-dep break: `ReconnectService` already depends on `GameService` for
`handleDrawBarrel` / `startTurn`. Implementation Epic must either:

1. Inject `GameTurnService` into `ReconnectService` instead of `GameService`
   for auto-draw / AFK paths, or
2. Keep `GameService::handleDrawBarrel()` as a one-line delegate while
   `ReconnectService` is migrated in the same Epic.

Option 2 is lower risk for the first cut.

### Secondary extraction (deferred): `GameStartService`

**Not in the first refactor Epic.** `handleStartGame()` is ~230 lines and
self-contained, but it is touched less often than turn logic. Extract only if
`GameService` remains >500 lines after `GameTurnService` lands.

## Explicit non-goals

- No protocol, economy, timer threshold, or state-machine changes.
- No extraction from `ApartmentService` or `AdminService`.
- No rename of existing public `GameService` method signatures until callers
  are migrated (backward-compatible delegates acceptable during transition).

## Consequences

**Positive:**

- `GameService` drops to ~400–450 lines (orchestration + start game).
- Turn/draw cluster becomes testable in isolation (mirrors ADR-002 precedent).
- Reduces merge-conflict surface before mandatory 1000-line refactor.

**Negative:**

- One new service + DI wiring in `server.php` bootstrap.
- `ReconnectService` / `GameService` circular dependency must be revisited
  carefully (ADR-008 precedent exists).
- Manual test files referencing `GameService` turn methods need import
  updates or continue calling through `GameService` delegates.

## Compatibility

No protocol, database, or economy changes. Existing integration tests must
pass without behaviour change (delegates preserve call sites).

## Amendments to other ANCHOR documents

None until Status moves from **Proposed** → **Accepted** and implementation
Epic completes. On acceptance, add citation under `ANCHOR_CORE.md` § Module
Boundaries / File Size Policy.

## Implementation Epic (separate, not part of this ADR)

When accepted, scope as **EPIC-17.1** (or next available):

1. Create `GameTurnService.php` with moved methods (copy, do not rewrite).
2. `GameService` delegates; `server.php` wires DI.
3. Update `ReconnectService` to call turn service where needed.
4. Run full `tests/Manual/` regression; no new behaviour.

Estimated diff: ~400 lines moved, ~50 lines wiring — within Rule 12 limits
if done as move-only.
